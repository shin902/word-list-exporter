# My 暗記帳

フラッシュカード形式で学習できるWebアプリケーション

## 使い方

1. `index.html` をブラウザで開く
2. 「設定」からGemini API Keyを設定（画像インポート機能を使う場合）
3. 「一覧表示」→「追加」から単語カードを手動登録、または「インポート」から画像をアップロード
4. 「学習開始」でランダムに出題される問題を学習

## 機能

- ✅ ホーム画面
- ✅ 単語カード追加機能
- ✅ 単語カード一覧表示（カテゴリ別）
- ✅ 単語カード削除機能
- ✅ ランダム出題による学習モード
- ✅ 上付き・下付き文字サポート（例: `x^2`, `H_2O`）
- ✅ ローカルストレージでのデータ永続化
- ✅ 画像からの赤字抽出インポート機能（Gemini Vision API使用）

## 画像インポート機能のセットアップ

画像から単語カードをインポートする機能を使うには、Gemini API Keyが必要です。

### 1. Gemini API Keyの取得

1. [Google AI Studio](https://aistudio.google.com/app/apikey) にアクセス
2. Googleアカウントでログイン
3. 「Create API Key」をクリックしてAPI Keyを生成
4. 生成されたAPI Key（`AIza`で始まる39文字の文字列）をコピー

### 2. API Keyの設定

1. アプリのホーム画面で「設定」ボタンをクリック
2. Gemini API Keyの入力欄に取得したAPI Keyを貼り付け
3. 「保存」ボタンをクリック

#### API Keyの削除

不要になった場合や共有PCで使用した後は、以下の手順でAPI Keyを削除できます：

1. 設定画面で「API Keyをクリア」ボタンをクリック
2. 確認ダイアログで「OK」をクリック
3. API Keyがローカルストレージから完全に削除されます
4. 必要に応じて [Google AI Studio](https://aistudio.google.com/app/apikey) でAPI Keyを無効化してください

### 3. 画像のインポート

1. 「一覧表示」→「インポート」をクリック
2. カテゴリ名を入力（デフォルトは「英単語」）
3. 赤字が含まれる画像を選択
4. 「赤字を抽出してインポート」ボタンをクリック
5. 認識されたカードを確認・編集して保存

### ⚠️ セキュリティに関する重要な注意事項

このアプリケーションは**完全にブラウザ上で動作**します（GitHub Pagesでホスティング）。そのため、API KeyをlocalStorageに保存する必要があります。

#### API Keyのセキュリティ対策と限界

**実装済みの対策**:
- ✅ Web Crypto APIによるAES-GCM暗号化
- ✅ XSS対策（入力サニタイズ、CSP設定）
- ✅ 入力長制限（DoS攻撃対策）

**限界と残存リスク**:
- ⚠️ **暗号化の限界**: 暗号化していますが、復号化コードもブラウザ上にあるため、攻撃者が同じ環境を再現すれば復号化可能です
- ⚠️ **DevToolsでの閲覧**: ブラウザの開発者ツールを使えば、技術者はAPI Keyを取り出せます
- ⚠️ **ブラウザ拡張機能**: 悪意のあるブラウザ拡張機能がlocalStorageにアクセスできる可能性があります
- ⚠️ **物理的アクセス**: デバイスにアクセスできる第三者がAPI Keyを読み取れる可能性があります

#### なぜこの設計なのか？

このアプリは以下を優先して設計されています：

1. **簡単に使える**（サーバー不要、すぐ試せる）
2. **無料で動く**（GitHub Pages、サーバー維持費ゼロ）
3. **コードが理解しやすい**（学習教材として）

セキュリティを最優先するなら、バックエンドサーバーが必要です。しかし、それでは「簡単に試せる」という教育用アプリの利点が失われます。

**トレードオフを理解した上で、ご自身の判断で使用してください。**

#### ✅ このアプリが適している場合

- ✅ 個人のデバイスで学習目的で使用
- ✅ 技術者が自己責任で使用
- ✅ Gemini APIの無料枠を試す
- ✅ 短期的なプロトタイプ作成

#### ❌ このアプリが適さない場合

- ❌ 共有PCでの使用
- ❌ 本番環境での使用
- ❌ 機密情報の処理
- ❌ 他人にサービスとして提供
- ❌ 商用利用

#### セキュリティのベストプラクティス

このアプリを使用する場合は、以下を守ってください：

1. **個人のデバイスでのみ使用**: 共有PCや公共のPCでは使用しない
2. **信頼できるブラウザ拡張機能のみ**: 不明な拡張機能をインストールしない
3. **使用後は削除**: 不要になったら設定画面で「API Keyをクリア」を実行
4. **定期的なローテーション**: [Google AI Studio](https://aistudio.google.com/app/apikey)でAPI Keyを定期的に再生成
5. **無料枠の範囲で使用**: 予期せぬ課金を防ぐため、無料枠を超えないよう注意

#### より安全な代替案（上級者向け）

本格的に使用する場合は、以下のアーキテクチャを検討してください：

**方法1: バックエンドプロキシ**
```
ブラウザ → あなたのサーバー → Gemini API
           ↑ サーバーでAPI Keyを管理
           ↑ ユーザーには見えない
```
- Vercel/Renderの無料枠で実装可能
- Google Sign-Inでユーザー認証

**方法2: Chrome拡張機能化**
- `chrome.storage.local`は他のサイトからアクセス不可
- ただし、Chrome Webストアの審査が必要

**このアプリの位置づけ**: 教育・学習用のプロトタイプとして最適化されています。セキュリティが最優先の場合は、上記の代替案を検討してください。

### トラブルシューティング

画像インポート時にエラーが発生した場合：

**「API Keyが無効です」エラー**
- 設定画面でAPI Keyが正しく入力されているか確認してください
- Google AI StudioでAPI Keyが有効になっているか確認してください

**「APIのリクエスト上限に達しました」エラー**
- 1日のリクエスト数が上限（1,500回）に達しています
- 翌日まで待つか、Google AI Studioで有料プランを検討してください

**「赤字のテキストが見つかりませんでした」エラー**
- 画像に赤字が含まれているか確認してください
- 画像の解像度が十分か確認してください（推奨: 最低でも800x600以上）

**「Gemini APIからのレスポンスの解析に失敗しました」エラー**
- インターネット接続を確認してください
- しばらく時間をおいてから再度お試しください
